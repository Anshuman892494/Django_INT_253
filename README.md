# Django Project

## How to run the project

Every time you want to run the project, open your terminal in the root folder (`c:\Users\anshu\OneDrive\Desktop\Django`) and run the following commands:

1. **Activate the virtual environment:**
   ```powershell
   .\myenv\Scripts\activate
   ```

2. **Start the development server:**
   ```powershell
   python manage.py runserver
   ```

Once running, you can access your site at `http://127.0.0.1:8000/`.

Press `Ctrl + C` in the terminal to stop the server.
